BAREVoiceJP (Windows x64) 配布パッケージ
========================================

BAREVoiceJP は、右 Alt を押している間だけ録音し、離した瞬間にローカルで
文字起こしして、アクティブなウィンドウへ Ctrl+V で貼り付ける
Push-to-Talk 音声入力アプリです。

推論は sherpa-onnx / ONNX Runtime によりすべてローカルで完結します。
音声や認識結果がクラウドへ送信されることはありません。アカウント登録も
不要です。


1. 動作環境
-----------

  OS        : Windows 10 / 11 (x64)
  ランタイム: Microsoft Edge WebView2 Runtime
              (Windows 11 は標準搭載。Windows 10 は Evergreen 版が必要)
              Microsoft Visual C++ 2015-2022 再頒布可能パッケージ (x64)
              (多くの Windows 10/11 には導入済み。未導入の場合は
               https://aka.ms/vs/17/release/vc_redist.x64.exe を実行)
  マイク    : 入力デバイスが 1 つ以上
  ディスク  : モデル用に 160 MB 〜 700 MB
              (Haas-ja-v1.0 の int8 量子化版は約 480 MB)

WebView2 Runtime が入っていない場合は、Microsoft の配布ページから
Evergreen Bootstrapper をインストールしてください。
  https://developer.microsoft.com/microsoft-edge/webview2/


2. インストールと起動
---------------------

この ZIP はインストーラーではありません。任意のフォルダへ展開して
BAREVoiceJP.exe を直接実行します。

  1. ZIP を任意のフォルダへ展開します。
     例: %LOCALAPPDATA%\Programs\BAREVoiceJP
     Program Files 配下へ置く場合は管理者権限が必要になるため、
     ユーザーフォルダ配下を推奨します。

  2. BAREVoiceJP.exe をダブルクリックします。
     初回起動時にオンボーディング画面が表示されます。

  3. 使用するモデルを選び、「ダウンロード」を実行します。
     モデル本体はこの ZIP に含まれていません。ダウンロード完了後、
     モデルは BAREVoiceJP.exe と同じフォルダの models\ に保存されます。

  4. 右 Alt を押しながら話し、離すと認識結果が貼り付けられます。
     200 ms 未満の押下は誤操作として破棄されます。

  設定画面はタスクトレイのアイコンを右クリック →「設定」から開きます。
  アプリの終了もトレイメニューから行えます。二重起動は自動的に防止されます。


3. 基本的な使い方
-----------------

  録音       : 右 Alt を押している間
  貼り付け   : 右 Alt を離すと、認識結果をクリップボード経由で Ctrl+V
  設定       : タスクトレイのアイコンを右クリック →「設定」
  終了       : タスクトレイのアイコンを右クリック →「終了」

設定画面では次の項目を変更できます。

  - 操作        : ホットキー、自動起動、操作モード
  - モデル      : モデルの選択・ダウンロード・削除
  - マイク      : 入力デバイス、入力レベル
  - 辞書        : words.txt / replacements.json の編集
  - 履歴        : 直近 10 件の認識結果のコピー・全件クリア
  - 通知音      : 開始・終了音のテーマと音量
  - ガイド      : 使い方と技術スタック

words.txt と replacements.json は保存すると次回の発話から反映されます。
hotwords.txt は現行エンジンでは認識に反映されません。

貼り付けは Ctrl+V 固定です。貼り付け先が Ctrl+V を受け付けない場合は、
認識結果がクリップボードに残ります。


4. Windows SmartScreen の警告が出た場合
----------------------------------------

このアプリの実行ファイルはコード署名されていません。そのため、
ダウンロード直後の ZIP や exe に対して Windows が警告を表示することが
あります。次の手順で確認してください。

■ ZIP がブロックされている場合

  1. ダウンロードした ZIP を右クリック →「プロパティ」
  2. 「全般」タブ下部の「セキュリティ: このファイルは他のコンピューター
     から取得したため、ブロックされている可能性があります」を確認
  3. 「ブロックの解除」にチェック →「OK」
  4. ZIP を展開する

■ 「Windows によって PC が保護されました」と表示された場合

  1. 警告画面の「詳細情報」をクリック
  2. 表示された発行元とファイル名を確認
  3. 「実行」をクリック

  警告画面に「詳細情報」が表示されない場合は、組織のポリシーで実行が
  制限されています。管理者に確認してください。

■ 注意

  - SmartScreen や Microsoft Defender を無効化する必要はありません。
    警告を回避するためにセキュリティ機能をオフにしないでください。
  - 実行前に、配布元がこのリポジトリの GitHub Releases であることと、
    添付の .sha256 ファイルの値が一致することを確認してください。
  - 社内配布の場合は、社内の配布手順とウイルス対策製品の運用に従って
    ください。


5. SHA256 の確認方法
--------------------

配布 ZIP には同名の .sha256 ファイルが添付されています。値が一致しない
場合は実行しないでください。

PowerShell の場合:

  Get-FileHash .\BAREVoiceJP-<version>-win64.zip -Algorithm SHA256

  # .sha256 ファイルの内容と比較する
  Get-Content .\BAREVoiceJP-<version>-win64.zip.sha256

コマンドプロンプトの場合:

  certutil -hashfile BAREVoiceJP-<version>-win64.zip SHA256

表示されたハッシュ値（16 進数、大文字小文字は問いません）が .sha256
ファイルの値と一致すれば正常です。


6. データの保存場所
-------------------

設定・辞書・履歴・ログ・モデルは、すべて BAREVoiceJP.exe と同じ
フォルダに保存されます。カレントディレクトリには依存しません。

  BAREVoiceJP\
    BAREVoiceJP.exe
    sherpa-onnx-c-api.dll
    onnxruntime.dll
    onnxruntime_providers_shared.dll
    words.txt                 辞書（正式表記 : 代表読み）
    replacements.json         完全一致置換
    hotwords.txt              ホットワード（現行エンジンは未対応）
    config.toml               設定（初回起動後に自動生成）
    stats.json                累積実績（文字数と貼り付け回数のみ）
    history.json              認識履歴（直近 10 件、本文を含む）
    models\                   ダウンロードしたモデル
    logs\app.log              実行ログ（5 MiB でローテーション）

  - 音声はメモリ上だけで処理され、ファイルへ保存されません。
  - 認識結果の本文は history.json に直近 10 件だけ保存されます。
    不要な場合は設定画面の「履歴」→「全件クリア」で削除できます。
  - 自動起動を有効にすると、HKCU\Software\Microsoft\Windows\
    CurrentVersion\Run に登録されます。管理者権限は使いません。


7. アンインストール
-------------------

  1. 設定画面で自動起動をオフにします（有効にしていた場合）。
  2. タスクトレイメニューからアプリを終了します。
  3. BAREVoiceJP.exe を配置したフォルダを削除します。
  4. デスクトップやスタートメニューにショートカットを作成した場合は、
     それらも削除します。

レジストリの Run キーは、設定画面で自動起動をオフにすると削除されます。
フォルダを削除する前にオフにしてください。


8. 困ったとき
-------------

■ モデルをダウンロードできない

  - ネットワーク接続とプロキシ設定を確認してください。
  - 社内サーバーや共有フォルダから配布する場合は、config.toml の
    model_base_url を設定してください。設定方法はリポジトリの README を
    参照してください。
  - モデルの配布元に接続できない場合は、設定画面の「モデル」タブに
    エラーが表示されます。

■ アプリが起動しない /「VCRUNTIME140.dll が見つかりません」と表示される

  Microsoft Visual C++ 2015-2022 再頒布可能パッケージ (x64) を
  インストールしてください。
    https://aka.ms/vs/17/release/vc_redist.x64.exe

■ 設定画面が表示されない

  - WebView2 Runtime がインストールされているか確認してください。
  - logs\app.log にエラーが記録されている場合は、不具合報告に添付して
    ください。

■ 録音できない / マイクが認識されない

  - 設定画面の「マイク」タブで入力デバイスを選択してください。
  - Windows の「設定」→「プライバシーとセキュリティ」→「マイク」で、
    アプリのマイクアクセスが許可されているか確認してください。

■ 貼り付けられない

  - 貼り付け先のアプリが Ctrl+V を受け付けるか確認してください。
  - 認識結果はクリップボードに残っているため、手動で Ctrl+V できます。
  - 管理者権限で動作するアプリへは、権限の異なるプロセスから入力できない
    場合があります。

■ ログを確認したい

  BAREVoiceJP.exe と同じフォルダの logs\app.log を開いてください。
  認識結果の本文や音声データはログへ出力されません。

    https://github.com/benzo322/barevoicejp

  不具合報告・要望:
    https://github.com/benzo322/barevoicejp/issues

不具合を報告する際は、次の情報を添えてください。

  - BAREVoiceJP のバージョン（配布 ZIP のファイル名）
  - Windows のバージョン（例: Windows 11 23H2）
  - 使用しているモデル
  - 現象と再現手順
  - logs\app.log の関連部分（認識結果の本文は含まれません）

ソースコードからのビルド方法、モデルの配布元の切り替え、設定ファイルの
詳細は、リポジトリの README.md を参照してください。
